## What landed

- `PyMiliDatabase.nodes()` → `np.float32` `(n_nodes, mesh_dim)`.
- `PyMiliDatabase.connectivity(class_name=None)` → element **LABELS**
  form, `np.int32` `(n_elem, nodes_per_elem + 1)` (node columns
  label-substituted, trailing column = raw material number, part
  column dropped); dict over element classes when `class_name=None`.
- Established the owned-`Vec<T>` → `into_pyarray_bound(py)` →
  `.reshape((rows, cols))` zero-FFI-copy 2-D return path under
  `allow_threads`; helpers pinned for M3 reuse.
- Two `mili-rs` core parity fixes for the cross-fragment merges
  (`nodes()` is dedup-by-label on `np.unique(return_index=True)` then
  sorted indices — not plain concat; `connectivity()` row-concats the
  per-fragment **label** form, not the raw stream).
- Returned-array writability decision: leave writable (upstream
  `nodes()` / `connectivity()` are `np.concatenate` / `.copy()`,
  already writable); the `np.frombuffer` read-only question is
  re-flagged for M3 (state data).
